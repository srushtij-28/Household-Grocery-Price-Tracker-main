# Household Grocery Price Tracker

## About

A command-line Python application to manage grocery items,
record prices from different shops, compare prices, and
identify the cheapest shop.

## Features

- Add, view, update, and delete grocery items
- Record grocery prices from different shops
- View price history
- Compare prices between shops
- Find the cheapest shop
- Calculate estimated shopping costs
- Store data using JSON files

## Technologies Used

- Python
- JSON
- File Handling
- Functions
- Modules

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Run:

   python main.py

No external libraries are required.

## Storage

All grocery and price records are stored locally
in JSON files inside the data folder.
